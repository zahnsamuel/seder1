30-DAY PILOT

Learn the canon by opening sources.

This pilot is for adults beginning Jewish textual learning. You do not need a study partner. You do need patience, attention, and the willingness to attempt a source before seeking help.

1
Follow one clear daily session

The 30-Day Journey gives each day a primary learning field while preserving spaced return and source evidence.

2
Use repair before pushing ahead

If a reading move is uncertain, take the one-minute repair and return to the source.

3
Keep a source notebook

Save questions and observations so learning does not vanish when a session ends.

4
Use the full text when ready

Anchor units link to full sources; the Daf Workbench remains the central full-page Gemara experience.
