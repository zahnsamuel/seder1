# Independent learner pilot operations

Audience: adults 18–35 beginning Jewish textual learning independently.

Run a 30-day cohort of 5–10 learners. Ask participants to use the 30-Day Journey, answer source questions honestly, save questions in the notebook, and report unclear moments through the pilot feedback channel.

Collect only learning behavior needed to improve the experience: session openings, attempts, accuracy, repairs attempted, reviews due, and voluntary notes. Do not present Seder as a source of personal halakhic rulings.

Success signals: at least 70% complete week one; learners return for a retrieval session; learners can explain a source move in a second context; and reported confusion points are specific enough to improve a source, explanation, or repair.
