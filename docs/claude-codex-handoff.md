# Claude ↔ Codex handoff

## Purpose

Claude and Codex collaborate on Seder through written artifacts, not live shared control. Claude is strongest as a curriculum drafter and critical reader; Codex is strongest as the implementation and verification owner.

## Claude should provide

- draft source sequences with precise citations;
- an explanation of the skill each source teaches;
- two or more transfer contexts for each skill;
- proposed prompts, plausible distractors, and feedback;
- concerns about pedagogy, tone, historical framing, or legal overreach.

## Codex will do

- turn approved material into Seder curriculum nodes and interactions;
- preserve learner progression, review, and data constraints;
- add tests and check the local experience;
- report concrete changes, files, and remaining risks.

## Handoff format

Use one proposal per block:

```text
Goal:
Learner level:
Primary source and citation:
Reading skill:
Two transfer contexts:
Prompt / choices / correct answer:
Feedback:
Potential sensitivities or study-aid boundary:
```
