# Shabbat foundation block

Shabbat is Seder's second deep Gemara block. Where Berakhot starts with a question and its textual grounding, Shabbat trains case mapping: people, domains, action, category, distinction, and the reason a rule protects.

| Stage | Current experience | Learner evidence |
|---|---|---|
| Counted Mishnah | `shabbat-arc.html` | Predict that a numbered opening contains root cases and extensions. |
| People, domains, action | `shabbat-arc.html` | Map poor person, homeowner, inside, outside, and transfer. |
| Category and distinction | `shabbat-arc.html` | Explain what shared category joins cases and what feature differentiates them. |
| Second source | Mishnah Shabbat 1:2 / Shabbat 9b in `shabbat-arc.html` | Recognize a tractate topic shift and explain the timing concern. |
| Interactive Daf map | `daf-workbench.html?tractate=shabbat` | Label line roles and explain a transition. |
| Deliberate retrieval | `lab.html?tractate=shabbat` | Rebuild one weak case-reading move. |
| Transfer | `gemara-unseen-check.html` and Eruvin comparison | Map a fresh physical/legal case before deciding its category. |
