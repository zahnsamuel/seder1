# Seder pilot content review

Before external pilot distribution, a qualified Jewish educator should review the seven pilot sessions and the seven repair cards.

For each item, verify:

1. Exact primary-source citation and locator.
2. Exact Hebrew/Aramaic text, including spelling and punctuation where relevant.
3. Translation for accuracy and beginner readability.
4. Explanation for genre, historical context, and interpretive restraint.
5. Halakhic boundary language: no study prompt should be presented as personal psak.
6. Distractors: wrong answers should be plausible but not misleading about Jewish practice or belief.

Current status: **pending external scholarly review**. Seder's internal automated tests validate structure and route integrity, not religious or textual authority.
