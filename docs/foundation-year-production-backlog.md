1. Finish live QA through Berakhot 2b, independent reading, Canon Connection, and My Journey.
2. Expand Berakhot Block 1 from its opening arc into ten linked sessions with two contrasting texts.
3. Produce Shabbat Block 2 and Eruvin Block 3 using the same source-map, transfer, and retrieval template.
4. Produce Pesachim Block 4 and Bava Metzia Block 5; link each to its natural Chumash, Tefillah, and ethical source.
5. Add the first six language/retrieval sessions to `data/language-ladder.json` with source contexts from the five Gemara blocks.
6. Apply the release-review register to every new source before it is called verified.
7. Run a five-learner private pilot only after hosted account isolation and reviewer approval are complete.

## Definition of done for a block

- Ten learner-visible sessions, a delayed retrieval, a transfer, and a Canon Connection.
- No required typing gate or hidden next action.
- Source review record complete; sensitive content has a study-not-advice boundary.
- New-learner QA and full automated suite pass.
