# Jewish Learning Academy Transition Implementation Plan

This document turns the investor-meeting notes and product roadmap into a practical build plan. The goal is to move the product from "Seder as a broad Jewish learning app" toward "Jewish Learning Academy as a skills-first path from 0 to 1 in Jewish learning."

## Product Direction

Jewish Learning Academy should help a learner become Jewishly literate: able to open the Jewish canon, recognize what kind of text they are seeing, understand the learning move being asked of them, and continue learning with confidence.

The product should be skills-first. Content remains essential, but each source, unit, and session should exist because it teaches or tests a named capability in the graph.

## Near-Term Build Priorities

1. Make the front door explicitly Jewish Learning Academy.
2. Rewrite placement around capability profile and rhythm.
3. Tighten Today into a one-session Academy flow.
4. Expand the foundation graph toward a few hundred interlocking skills.
5. Add more first-class non-Gemara canon routes.
6. Define visible graduation levels for Jewish literacy.
7. Keep Supabase account isolation as the hard pilot blocker.

## App Copy Principles

- Say "Jewish Learning Academy" in learner-facing product identity.
- Avoid making "Seder" the main brand on entry screens.
- Present Gemara as a laboratory for Jewish learning, not the entire product.
- Prefer "skill", "capability", "daily session", "path", "foundation", and "canon literacy".
- Make every screen answer: "What can I do now that I could not do before?"

## Main Surface Targets

### Front Door

The first screen should communicate that Jewish Learning Academy helps learners become Jewishly literate through placement, one clear next move, and daily rhythm.

### Placement

Placement should communicate that the Academy is finding the learner's starting point, not judging prior schooling. The result should be a capability profile and a first daily session.

### Today

Today should communicate one clear session, sized for the learner's rhythm, with recovery after missed days treated as normal.

### My Path

My Path should communicate evidence-based progress through a capability graph, not just pages completed.

## Product Risks

- Overbuilding Gemara while underbuilding the broader 0-to-1 literacy path.
- Letting content coverage substitute for skill mastery.
- Making the graph visible before the learner has enough confidence to understand it.
- Making assessment feel like school failure instead of guided calibration.
- Shipping real pilots before account isolation is verified.
