# Seder curriculum quality standard

Every learner-facing activity must have:

1. An exact primary-source reference and a stable source link.
2. Hebrew/Aramaic shown in the learning space, with a faithful learner-facing translation available on demand.
3. One observable skill, explicit prerequisite skills, and a mastery-evidence statement.
4. Questions whose correct answers are randomized in presentation and whose distractors represent plausible misunderstandings.
5. Feedback that explains the textual move rather than merely marking an answer right or wrong.
6. A reviewed status, version date, and a clear study-aid / non-pesak boundary when relevant.

Before publishing a new sequence, test it with at least one learner in the intended audience. Record where the learner loses the thread, then revise the source framing, translation, or question before adding more material. The current pilot set includes Berakhot, Shabbat, Eruvin, Pesachim, Sukkah, Ketubot, Bava Kamma, Bava Metzia, Chullin, and Niddah.
