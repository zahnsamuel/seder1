# Seder curriculum blueprint

## Learner promise

Seder takes an English-speaking adult who can sound out Hebrew from first contact with Jewish sources to responsible independent navigation of the canon. It does not treat Gemara, Chumash, Halakha, Tefillah, Thought, history, or character as separate languages. Each is a different use of shared reading tools.

## Evidence standard

A learner advances when they can demonstrate a skill in at least two distinct source contexts. A lesson completion is not evidence by itself. The minimum evidence unit is: source text, learner response, accuracy signal, context label, and a later retrieval.

## Four phases

1. **Reading foundations** — Hebrew/Aramaic signals, source type, Mishnah case, and the first Gemara question.
2. **Canon connections** — Torah, prayer, halakhic reception, conceptual claims, character, history, and careful comparison.
3. **Gemara fluency** — proof, objection, response, line-function mapping, and transfer into new tractates.
4. **Integrated reading** — interpretation, conceptual disagreement, halakhic source chains, and independent source navigation.

Each phase ends in a checkpoint. The following phase remains locked until that checkpoint is passed.

## Gemara pathway

The beginner runway begins with Berakhot because it introduces Mishnah, Torah citation, prayer, time, and the opening question of a sugya. It then revisits the same repertoire across Shabbat, Eruvin, Sukkah, Pesachim, Bava Metzia, Bava Kamma, Ketubot, Chullin, and Niddah. The long-term Shas map expands tractate by tractate; no learner is expected to finish one tractate before meeting the rest of the canon.

## Content node requirements

Every learner-facing node must include:

- a precise citation and source setting;
- readable Hebrew/Aramaic and learner-facing translation;
- source vocabulary or argument signals where relevant;
- two checks in distinct source contexts;
- explanatory feedback that names the reading move;
- explicit limits when a source concerns practical halakha.

## Near-term content build

1. Complete the Berakhot runway from opening Mishnah to independent short-sugya reading.
2. Build comparable five-to-nine session arcs for Shabbat, Eruvin, Pesachim, Sukkah, and Bava Metzia.
3. Add cross-canon bridge sessions after each tractate arc: Torah source, later halakhic reception, conceptual question, and historical setting.
4. Add independent checkpoints using a source the learner has not previously encountered.
