# Berakhot foundation block

This is Seder's first substantial Gemara sequence for an English-speaking beginner. It already moves beyond a single Daf image and should be treated as the model for later tractate blocks.

| Move | Current learning experience | Evidence target |
|---|---|---|
| Question signal | `language.html` | Predict what kind of answer a question word seeks. |
| Opening Mishnah | `berakhot-deep.html` | Identify case, question, and source-grounded response. |
| Proof and word-question | `berakhot-unit-2.html` | Explain what a verse or word-question contributes. |
| Independent signals | `berakhot-unit-3.html` | Map an unfamiliar short sequence before translation. |
| Mishnah grammar | `berakhot-unit-4.html` | Separate case, condition, and ruling. |
| Baraita and objection | `berakhot-unit-5.html` | Identify teaching, target, pressure, and distinction. |
| Live Daf map | `daf-workbench.html?tractate=berakhot` | Label line roles and explain one transition. |
| Deliberate retrieval | `berakhot-lab.html` | Rebuild a specific weak move. |
| Unseen transfer | `gemara-unseen-check.html` | Read a new mini-sugya with language and structure support. |

## Editorial completion criteria

Before calling the block production-complete, each source encounter needs the fields in `data/source-review-schema.json`: exact reference/edition, checked translation, context, language support, assessment rationale, safety boundary, and a second source context. The existing instructional sequence is the prototype; the next work is to verify and expand its source packets with scholarly review rather than add unreconciled volume.
