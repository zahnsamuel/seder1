# Flagship tractate blocks

Each tractate below implements the common block template: orient to a concrete Mishnah, build language and argument skills, meet a second source or topic shift, map the Daf, retrieve a weak move, and transfer to an unfamiliar passage.

| Tractate | Distinct reading habit | Second source / deepening move | Transfer | Deep source arc |
|---|---|---|---|---|
| Pesachim | Separate action, time, tool, and an ambiguous word. | Mishnah Pesachim 1:2: set a reasonable limit on open-ended concern. | Carry case-variable mapping into Shabbat. | `pesachim-arc.html` |
| Eruvin | Read a measurement as a category with a reason. | Mishnah Eruvin 1:2: compare `and` and `or` in a Tannaitic dispute. | Compare the twenty-cubit measure with Sukkah. | `eruvin-arc.html` |
| Sukkah | Trace physical validity through reason to source. | Its tractate arc treats the reason behind the height requirement and its source role. | Recognize measurement-plus-purpose in Eruvin. | `sukkah-arc.html` |
| Bava Metzia | Keep object, claims, evidence, and response distinct. | The arc asks when a symmetric response changes with asymmetric evidence. | Use Berakhot's argument map in civil law. | `bava-metzia-arc.html` |
| Bava Kamma | Differentiate legal categories before naming their shared principle. | Trace `av` and `toldah` stakes and the Torah sources in Exodus 21–22. | Combine category-sorting with Bava Metzia evidence analysis. | `bava-kamma-arc.html` |

## Required review

These instructional arcs are the current deep prototypes, not a substitute for complete source certification. Before a block is marked production-complete, review every source encounter against `data/source-review-schema.json`, including exact edition, translation, context, assessment rationale, safety boundary, and a second independent source context.
