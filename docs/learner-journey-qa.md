# Independent learner journey QA

Run this as one new adult learner. The aim is not to click every page; it is to confirm that the learning loop makes sense without a teacher or study partner.

| Moment | Expected learner experience | Evidence to capture |
|---|---|---|
| Arrival | The landing page explains one integrated Jewish-learning journey and a usable first move. | Screenshot and route selected. |
| Placement | Questions sample reading and reasoning without pretending to certify expertise. | Recommended next skill. |
| First source | Hebrew/Aramaic, guided translation, key terms, and focus controls are all visible without hunting. | One completed source line. |
| Answer | Choices are shuffled; feedback says why, and Continue is directly below the answer feedback. | Correct and incorrect answer states. |
| Repair | A missed or uncertain answer produces a targeted source, contrast, and transfer move. | Repair route and saved evidence. |
| Return | A later visit surfaces a due review and one understandable next step. | Review item and XP/mastery change. |
| Connection | A non-Gemara encounter returns toward the Gemara spine and offers no more than one meaningful lateral link. | Completion screen. |
| Boundary | Legal, pastoral, or practical material labels study as study rather than advice. | Boundary copy. |

## Exit criteria

The journey passes only if a new learner can explain what they did, why their next step follows, and where to get language support—without relying on hidden developer controls or a local shared `demo` profile.
